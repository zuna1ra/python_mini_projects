# Student Management System

A console-based Python application used to manage student records.

## Features

- Add Student
- View Students
- Search Student
- Update Student Marks
- Delete Student
- Automatic Grade Calculation

## Technologies Used

- Python

## Concepts Used

- Functions
- Loops
- Lists
- Dictionaries
- Conditional Statements

## How to Run

```bash
python student_management_system.py
```
